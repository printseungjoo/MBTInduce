# 프론트 협업 규칙 (백엔드 저장소)

## 절대 준수

- **`MBTInduce_frontend/` 디렉터리는 프론트 담당 전용 작업 공간이다.**
- 백엔드 구현·리팩터·문서 작업 시 **해당 폴더 안의 어떤 파일도 수정·삭제·추가하지 않는다.**
- Cursor/에이전트 작업 범위도 **`src/`**, **`prisma/`**, **`docs/`**(루트), 루트 설정 파일 등 **백엔드 영역만** 포함한다.

## 백엔드 구성 원칙

- API 필드명, 상태 변수 네이밍, 화면 분할(메인챗·시뮬·캘린더)은 **프론트 저장소를 참고용으로만 읽고**, 백엔드는 그에 **맞춘 계약(REST JSON 키, 타입)**을 유지한다.
- 계약 변경이 필요하면 **프론트 담당과 합의 후**, 백엔드 쪽 `docs/`(예: `frontend-api-types.example.ts`, API 요약)를 먼저 갱신한다.

## 검증

- PR/로컬 diff에서 `MBTInduce_frontend/` 아래 경로가 변경되지 않았는지 확인한다.
